# Интернет-магазин автозапчастей

Курсовой проект на Django. Индивидуальный вариант Д11-М3.

## Описание проекта

Веб-приложение для поиска, подбора и покупки автомобильных запчастей. Пользователи могут просматривать каталог, искать товары, выбирать совместимые с автомобилем детали, добавлять их в корзину, оформлять заказы и сохранять понравившиеся товары.

## Реализованные возможности

- Каталог автозапчастей с фотографиями, ценами и остатками.
- Поиск товаров по названию и артикулу.
- Фильтрация по категории, марке, модели и году автомобиля.
- Сортировка товаров и постраничная навигация.
- Регистрация, авторизация и личный кабинет пользователя.
- Гараж пользователя с сохранёнными автомобилями.
- Подбор запчастей по автомобилю из гаража.
- Предупреждение о несовместимости запчасти с автомобилем при оформлении заказа.
- Корзина с изменением количества и удалением товаров.
- Оформление заказов с проверкой складских остатков.
- Просмотр истории заказов и отмена заказов.
- Избранные товары с возможностью добавления и удаления.
- Уведомления о поступлении отсутствовавших товаров на склад.
- Административная панель для управления товарами и заказами.

## Структура проекта

- `accounts` — пользователи, профили, гараж, избранное и уведомления.
- `catalog` — каталог, категории, производители, автомобили и запчасти.
- `cart` — корзина покупателя.
- `orders` — оформление и управление заказами.
- `config` — настройки и маршрутизация Django.
- `templates` — общие HTML-шаблоны.

## Запуск проекта

1. Создать виртуальное окружение:

   `python -m venv venv`

2. Активировать виртуальное окружение в Windows PowerShell:

   `.\venv\Scripts\Activate.ps1`

3. Установить зависимости:

   `pip install -r requirements.txt`

4. Применить миграции:

   `python manage.py migrate`

5. При необходимости создать администратора:

   `python manage.py createsuperuser`

6. Запустить сервер:

   `python manage.py runserver 5001`

После запуска сайт будет доступен по адресу `http://127.0.0.1:5001/`.

Административная панель доступна по адресу `http://127.0.0.1:5001/admin/`.

## Индивидуальные задания

**Д11 — Подбор автозапчастей по автомобилю.** Реализованы модели автомобилей, совместимость запчастей, каскадная фильтрация по марке, модели и году, гараж пользователя и предупреждение о несовместимости.

**М3 — Избранное и уведомления.** Реализовано добавление запчастей в избранное, отображение состояния избранного и автоматическое создание уведомлений при появлении товара на складе.
